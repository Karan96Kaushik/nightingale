# Spanish Days 15–30

Everything taught in weeks three and four. Days 1–14 gave you chunks: enough soy, tengo, quiero, voy, hago, estoy, and fui to speak about yourself, your day, and yesterday. These sixteen days turn those chunks into full patterns — every person of the core verbs, the rest of the past tense, pronouns that replace nouns, and the tools to compare, predict, and instruct. Forms that are not in these lessons are still left out on purpose.

## Day 15 — Core verbs, full pattern

**Vocabulary:** tener, querer, ir, hacer — every person  
**Grammar:** full conjugation, tener que  
**Listen:** a dialogue with a group of friends  
**Practice:** describe a friend's plans and a group's plans

### Grammar

**Five people, one pattern each.** Days 1–14 only needed yo, tú, and sometimes nosotros for these four verbs. Now add él/ella and ellos/ellas, so you can talk about someone else and about a group without switching to a different verb. Tener que still means have to; hay que is the same idea without a person attached, for a rule that applies to everyone.

| | tener | querer | ir | hacer |
|---|---|---|---|---|
| yo | tengo | quiero | voy | hago |
| tú | tienes | quieres | vas | haces |
| él / ella | tiene | quiere | va | hace |
| nosotros | tenemos | queremos | vamos | hacemos |
| ellos / ellas | tienen | quieren | van | hacen |

Not yet: vosotros (tenéis, queréis, vais, hacéis). You will hear it in Spain; you still do not need to say it.

### Phrases

| Spanish | English | Note |
|---|---|---|
| Ella tiene dos hijos. | She has two children. | New person: él/ella. |
| Mis amigos tienen mucho trabajo. | My friends have a lot of work. | New person: ellos/ellas. |
| Él quiere viajar este año. | He wants to travel this year. | |
| Ellos quieren descansar. | They want to rest. | |
| Va al gimnasio todos los días. | He/she goes to the gym every day. | |
| Vamos a la playa el sábado. | We are going to the beach on Saturday. | |
| Hace la compra los domingos. | He/she does the shopping on Sundays. | |
| Hacen mucho ruido. | They make a lot of noise. | |
| Tengo que estudiar esta noche. | I have to study tonight. | Tener que, from day 4, now with any person: tienes que, tiene que. |
| Hay que llegar temprano. | You have to arrive early. | Hay que has no person — a rule for everyone. |
| ¿Qué tiene que hacer hoy? | What does he/she have to do today? | |
| Tienen que salir a las ocho. | They have to leave at eight. | |

### Dialogue — Weekend plans

- **Marta:** ¿Qué hace tu hermana este fin de semana? — What is your sister doing this weekend?
- **Alex:** Tiene que trabajar el sábado, pero el domingo quiere descansar. — She has to work Saturday, but Sunday she wants to rest.
- **Marta:** Mis amigos y yo vamos a la montaña. ¿Quieres venir? — My friends and I are going to the mountains. Do you want to come?
- **Alex:** Sí. ¿Qué tenemos que llevar? — Yes. What do we have to bring?
- **Marta:** Hay que llevar agua y comida. Ellos hacen la comida. — You have to bring water and food. They're making the food.
- **Alex:** Perfecto. Voy a preparar café para todos. — Perfect. I'll make coffee for everyone.

### Practice — Someone else, and a group

Describe what one friend has, wants, is going to do, and does — using tiene, quiere, va, hace. Then describe the same four things for a group of people, using tienen, quieren, van, hacen.

Starters: *Mi amigo/a tiene…* / *Quiere…* / *Va a…* / *Hace…* / *Mis amigos tienen… quieren… van… hacen…*

Say every person out loud before you write anything down. The pattern only sticks if you hear yourself use it.

## Day 16 — Stem-changing verbs

**Vocabulary:** poder, empezar, pedir, dormir; weather  
**Grammar:** e→ie, o→ue, e→i  
**Listen:** a forecast and a weekend conversation  
**Practice:** describe today's weather and one plan it affects

### Grammar

**The middle vowel changes, the endings don't.** These verbs use the same endings as day 10, but the stressed vowel in the middle of the verb shifts. Poder and dormir change o to ue. Empezar and querer (day 4) change e to ie. Pedir changes e to i. Nosotros keeps the original vowel, because that syllable isn't stressed.

| | poder (o→ue) | empezar (e→ie) | pedir (e→i) |
|---|---|---|---|
| yo | puedo | empiezo | pido |
| tú | puedes | empiezas | pides |
| él / ella | puede | empieza | pide |
| nosotros | podemos | empezamos | pedimos |
| ellos / ellas | pueden | empiezan | piden |

Dormir works the same as poder: duermo, duermes, duerme, dormimos, duermen.

Not yet: every stem-changing verb that exists. Learn these four and add more the same way when you meet them.

### Weather

Hace calor. Hace frío. Hace sol. Hace viento. Llueve. Nieva. Está nublado.

### Phrases

| Spanish | English | Note |
|---|---|---|
| Hace calor hoy. | It is hot today. | |
| Llueve mucho en abril. | It rains a lot in April. | |
| Cuando llueve, no puedo salir. | When it rains, I can't go out. | |
| ¿Puedes venir mañana? | Can you come tomorrow? | |
| Empiezo a trabajar a las nueve. | I start work at nine. | Combines with the day 2 clock. |
| La clase empieza pronto. | The class starts soon. | |
| Pido ayuda si la necesito. | I ask for help if I need it. | |
| ¿Qué pides normalmente? | What do you usually order? | Reuses the day 5 restaurant scene. |
| Duermo ocho horas. | I sleep eight hours. | |
| No duerme bien cuando hace calor. | He/she doesn't sleep well when it's hot. | |
| Podemos ir el sábado si no llueve. | We can go Saturday if it doesn't rain. | |
| Nieva en las montañas. | It snows in the mountains. | |

### Dialogue — Weekend weather

- **Sara:** ¿Qué tiempo hace hoy? — What's the weather like today?
- **Alex:** Hace sol, pero dicen que llueve mañana. — It's sunny, but they say it'll rain tomorrow.
- **Sara:** Entonces, ¿podemos ir a la playa hoy? — So, can we go to the beach today?
- **Alex:** Sí. Yo empiezo a trabajar a las tres, pero antes puedo ir. — Yes. I start work at three, but I can go before that.
- **Sara:** Perfecto. Si llueve mañana, pedimos comida y dormimos hasta tarde. — Perfect. If it rains tomorrow, we'll order food and sleep in.

### Practice — Weather and a plan

Say what the weather is like today. Then say one plan that depends on it, using at least two stem-changing verbs (puedo, empiezo, pido, duermo).

Starters: *Hoy hace…* / *Cuando llueve/hace sol…* / *Puedo… / No puedo…* / *Empiezo a…*

Say the whole verb out loud, not just the infinitive. Puedo, not poder; empiezo, not empezar.

## Day 17 — Direct object pronouns

**Vocabulary:** lo, la, los, las  
**Grammar:** replacing the noun  
**Listen:** short question-and-answer exchanges  
**Practice:** answer five questions without repeating the noun

### Grammar

**Say it once, then replace it.** Me lo llevo from day 12 already used this pattern as one fixed chunk. Now build it from parts. Lo replaces a masculine singular thing, la a feminine singular thing, los and las the plurals. The pronoun goes before a conjugated verb, or attaches to the end of an infinitive.

| Question | Answer | English |
|---|---|---|
| ¿Quieres el café? | Sí, lo quiero. | Do you want the coffee? Yes, I want it. |
| ¿Tienes la llave? | No, no la tengo. | Do you have the key? No, I don't have it. |
| ¿Ves los mensajes? | Sí, los veo. | Do you see the messages? Yes, I see them. |
| ¿Compras las manzanas? | Sí, las compro. | Are you buying the apples? Yes, I'm buying them. |

With an infinitive, the pronoun can go before the whole phrase or attach to the end: *Lo voy a comprar* or *Voy a comprarlo* — both mean "I'm going to buy it."

Not yet: indirect object pronouns (day 18) and combining the two together.

### Phrases

| Spanish | English | Note |
|---|---|---|
| ¿Quieres el postre? Sí, lo quiero. | Do you want dessert? Yes, I want it. | Reuses day 5 vocabulary. |
| ¿Tienes mi número? No, no lo tengo. | Do you have my number? No, I don't have it. | |
| La compro mañana. | I'll buy it tomorrow. | La = a feminine thing already mentioned. |
| ¿Ves la película? La veo ahora. | Are you watching the film? I'm watching it now. | |
| No los entiendo. | I don't understand them. | Los = masculine plural. |
| ¿Puedes ayudarme? Sí, puedo ayudarte. | Can you help me? Yes, I can help you. | Me and te attach the same way. |
| Las necesito para el viernes. | I need them by Friday. | |
| ¿Dónde está mi chaqueta? No la veo. | Where is my jacket? I don't see it. | |
| Voy a probármelo. | I'm going to try it on. | Builds on day 12's probarme. |
| Lo hago ahora mismo. | I'm doing it right now. | |

### Dialogue — Checking a list

- **Nuria:** ¿Tienes las entradas? — Do you have the tickets?
- **Alex:** Sí, las tengo aquí. — Yes, I have them here.
- **Nuria:** ¿Y el mapa? ¿Lo llevas? — And the map? Are you bringing it?
- **Alex:** No lo tengo. ¿Lo puedes traer tú? — I don't have it. Can you bring it?
- **Nuria:** Sí, lo traigo yo. ¿Compraste el agua? — Yes, I'll bring it. Did you buy the water?
- **Alex:** Todavía no. La compro de camino. — Not yet. I'll buy it on the way.

### Practice — Answer without the noun

Ask yourself five yes/no questions about things around you (¿Tienes…? ¿Ves…? ¿Quieres…?) and answer each one using lo, la, los, or las instead of repeating the noun.

Starters: *¿Tienes…? Sí, lo/la tengo.* / *¿Ves…? No, no lo/la veo.* / *¿Quieres…? Lo/la quiero.*

If you're not sure which pronoun fits, say the noun's gender out loud first: café is masculine, so lo; llave is feminine, so la.

## Day 18 — Gustar, and things that hurt

**Vocabulary:** me gusta / gustan, doler; body parts  
**Grammar:** indirect object pronouns  
**Listen:** someone describing likes and a minor ailment  
**Practice:** describe three likes or dislikes and one ache

### Grammar

**Gustar works backwards.** Day 9 only used me gusta with one thing or one verb. The thing you like is really the subject, so a plural thing needs gustan, not gusta. The person who likes it — me, te, le, nos, les — comes first. Doler (to hurt) and encantar (to love) and interesar (to interest) follow the exact same pattern.

| | one thing (gusta) | more than one thing (gustan) |
|---|---|---|
| me | me gusta | me gustan |
| te | te gusta | te gustan |
| le | le gusta | le gustan |
| nos | nos gusta | nos gustan |
| les | les gusta | les gustan |

Not yet: gustaría (would like) and combining gustar with the pronouns from day 17.

### Body parts

la cabeza, el estómago, la garganta, la espalda, el pie, el brazo, la mano

### Phrases

| Spanish | English | Note |
|---|---|---|
| Me gustan los libros de historia. | I like history books. | Plural thing, gustan. |
| Le gusta el fútbol. | He/she likes football. | |
| Nos gustan las playas tranquilas. | We like quiet beaches. | |
| ¿Te gustan los animales? | Do you like animals? | |
| Les encanta viajar. | They love travelling. | Encantar, same pattern. |
| Me interesa el arte moderno. | I'm interested in modern art. | Interesar, same pattern. |
| Me duele la cabeza. | My head hurts. | Doler, same pattern. |
| Le duelen los pies. | His/her feet hurt. | Plural body part, duelen. |
| ¿Te duele el estómago? | Does your stomach hurt? | |
| Nos duele la espalda después de correr. | Our backs hurt after running. | |
| No me gusta nada el ruido. | I don't like noise at all. | |
| Tengo que ir al médico. | I have to go to the doctor. | Ties into day 29. |

### Dialogue — How are you feeling

- **Diego:** ¿Qué tal? Te veo cansado. — How are you? You look tired.
- **Alex:** Me duele un poco la cabeza. Y me duele la espalda. — My head hurts a bit. And my back hurts.
- **Diego:** ¿Te gusta el té de manzanilla? Ayuda con el dolor. — Do you like chamomile tea? It helps with the pain.
- **Alex:** Sí, me gusta mucho. ¿Tienes? — Yes, I like it a lot. Do you have any?
- **Diego:** Sí. A mí también me duelen los pies. Caminé mucho hoy. — Yes. My feet hurt too. I walked a lot today.

### Practice — Likes and one ache

Say three things you like or don't like — mix one singular thing and one plural thing — using me gusta / me gustan. Then say one thing that hurts, using me duele or me duelen.

Starters: *Me gusta… / No me gusta…* / *Me gustan… / No me gustan…* / *Me duele… / Me duelen…*

Check the noun's number before you choose gusta or gustan — the pattern follows the thing, not the person.

## Day 19 — Possession and pointing

**Vocabulary:** tu, su, nuestro; este, ese, aquel  
**Grammar:** possessives and demonstratives  
**Listen:** two people comparing their belongings  
**Practice:** describe your things versus someone else's, and point to three objects

### Grammar

**More owners, and three distances.** Day 6 only used mi and mis. Now add tu/tus (your), su/sus (his/her/their), and nuestro/nuestra/nuestros/nuestras (our — this one matches gender as well as number). For pointing, este/esta is near you, ese/esa is near the listener, and aquel/aquella is far from both.

| Owner | Singular | Plural |
|---|---|---|
| my | mi | mis |
| your (tú) | tu | tus |
| his / her / their | su | sus |
| our | nuestro / nuestra | nuestros / nuestras |

| Distance | Masculine | Feminine |
|---|---|---|
| this (near me) | este | esta |
| that (near you) | ese | esa |
| that (far away) | aquel | aquella |

Not yet: the long possessive forms (mío, tuyo, suyo) used after the noun, like "es mío."

### Phrases

| Spanish | English | Note |
|---|---|---|
| ¿Es tu coche? | Is that your car? | |
| Su casa es muy grande. | His/her/their house is very big. | |
| Nuestro equipo gana siempre. | Our team always wins. | Nuestro matches equipo, masculine. |
| Nuestra familia es pequeña. | Our family is small. | Reuses the day 6 fact, now with nuestra. |
| ¿Dónde están tus llaves? | Where are your keys? | |
| Sus hijos viven en Chile. | Their children live in Chile. | |
| Este libro es interesante. | This book is interesting. | |
| Esa camisa es bonita. | That shirt is nice. | Near the listener. |
| Aquellos edificios son antiguos. | Those buildings (over there) are old. | Far from both. |
| ¿Te gusta esta canción? | Do you like this song? | Combines day 18's gustar. |
| Prefiero esta a esa. | I prefer this one to that one. | |
| Nuestros amigos llegan mañana. | Our friends arrive tomorrow. | |

### Dialogue — Comparing houses

- **Elena:** Esta es nuestra casa. Es pequeña, pero nos gusta. — This is our house. It's small, but we like it.
- **Alex:** Es muy bonita. ¿Y esa casa de allí, la grande? — It's very nice. And that house over there, the big one?
- **Elena:** Aquella casa es de mis vecinos. Su jardín es enorme. — That house belongs to my neighbours. Their garden is huge.
- **Alex:** ¿Tu jardín es este? — Is this your garden?
- **Elena:** Sí, este es nuestro jardín. Es pequeño, pero suficiente. — Yes, this is our garden. It's small, but enough.

### Practice — Yours, mine, and pointing

Describe two of your things using mi/mis, then describe two things that belong to someone else using su/sus or nuestro. Then point to three real or imagined objects — one near you, one near the listener, one far away — using este, ese, and aquel.

Starters: *Mi… es…* / *Su… es…* / *Nuestro/a… es…* / *Este/a… / Ese/a… / Aquel/aquella…*

Match nuestro to the noun's gender and number just like an -o/-a adjective. The others (mi, tu, su) only match number.

## Day 20 — Comparing things

**Vocabulary:** describing people, places, and food  
**Grammar:** más que, tan como, superlatives  
**Listen:** two people comparing restaurants  
**Practice:** compare two things you know using three structures

### Grammar

**More, less, equal, and the most.** Más...que and menos...que compare two unequal things. Tan...como compares two equal things. A handful of comparatives are irregular and don't use más: bueno becomes mejor, malo becomes peor. For a superlative, add el/la/los/las before más or menos.

| Spanish | English |
|---|---|
| Mi hermano es más alto que yo. | My brother is taller than me. |
| Este café es menos caro que ese. | This coffee is less expensive than that one. |
| Este plato es tan bueno como el otro. | This dish is as good as the other one. |
| Es el restaurante más caro de la ciudad. | It's the most expensive restaurant in the city. |
| Mi hermana mayor. Mi hermano menor. | My older sister. My younger brother. |

Not yet: tanto/a/os/as como for comparing amounts of a noun (as much money as, as many friends as).

### Phrases

| Spanish | English | Note |
|---|---|---|
| Mi ciudad es más tranquila que Madrid. | My city is quieter than Madrid. | |
| Este barrio es menos ruidoso que el centro. | This neighbourhood is less noisy than the centre. | Reuses centro from day 8. |
| Ella es tan simpática como su hermana. | She is as nice as her sister. | Reuses simpático/a from day 6. |
| Esta comida está tan rica como la de mi madre. | This food is as good as my mother's. | |
| Es el plato más caro del menú. | It's the most expensive dish on the menu. | |
| Es la playa más bonita que conozco. | It's the most beautiful beach I know. | |
| Mi trabajo es mejor que el anterior. | My job is better than my previous one. | Mejor, irregular. |
| El tráfico hoy es peor que ayer. | The traffic today is worse than yesterday. | Peor, irregular. |
| Mi hermano mayor vive en Barcelona. | My older brother lives in Barcelona. | |
| Ella es la menor de la familia. | She is the youngest in the family. | |

### Dialogue — Two restaurants

- **Ana:** ¿Qué restaurante prefieres, este o ese? — Which restaurant do you prefer, this one or that one?
- **Alex:** Este es más barato, pero ese tiene mejor comida. — This one is cheaper, but that one has better food.
- **Ana:** ¿Es tan bueno como el italiano cerca de casa? — Is it as good as the Italian place near home?
- **Alex:** Creo que sí. Y es menos ruidoso que el italiano. — I think so. And it's less noisy than the Italian one.
- **Ana:** Entonces vamos a este. Es la mejor opción. — Then let's go to this one. It's the best option.

### Practice — Compare two things

Pick two people, two cities, or two restaurants you know. Compare them using más...que, tan...como, and one superlative (el/la más...).

Starters: *…es más… que…* / *…es tan… como…* / *Es el/la más… de…*

Keep the adjective agreeing with the noun, the same as day 3's job endings and day 6's family adjectives.

## Day 21 — Week three review

**Review day.** Revise days 15–20. Speak for 5–10 minutes entirely in Spanish.

### Grammar

**Nothing new.** Reuse only what you can already say. Full tener, querer, ir, hacer for any person. Puedo, empiezo, pido, and duermo for the stem-changers. Lo, la, los, las for things already mentioned. Me gusta / me gustan and me duele / me duelen for likes and aches. Mi, tu, su, nuestro for ownership, and este, ese, aquel for pointing. Más que, tan como, and el/la más for comparing.

| Spanish | English |

| Me gusta(n)… Me duele(n)… | Likes and aches. |
| Mi… Tu… Su… Nuestro/a… | Possession. |
| Es más… que… Es tan… como… | Comparing. |

Not yet: any new tense or pattern. Today is for speaking, not a new chart.

### Phrases

| Spanish | English |
|---|---|

| Cuando hace frío, no puedo dormir bien. | When it's cold, I can't sleep well. |

### Dialogue — Three weeks in

- **Alex:** Este mes tengo que trabajar mucho, pero también quiero descansar. — This month I have to work a lot, but I also want to rest.
- **Sofía:** ¿Qué tal el nuevo trabajo? — How's the new job?
- **Alex:** Me gusta, pero a veces me duele la espalda de estar sentado. — I like it, but sometimes my back hurts from sitting.
- **Sofía:** ¿Puedes tomar descansos? — Can you take breaks?
- **Alex:** Sí, y mi jefe es más flexible que el anterior. Empiezo más tarde ahora. — Yes, and my boss is more flexible than the previous one. I start later now.

### Practice — Ten minutes, weeks one to three

Speak for five to ten minutes without switching to English. Cover a friend's plans, the weather and one thing it affects, one item you have or don't have, two likes and one ache, and one comparison.

Starters: *Mi amigo/a tiene…* / *Hoy hace… y puedo/no puedo…* / *¿Lo tengo? Sí/No…* / *Me gusta(n)… Me duele(n)…* / *…es más… que…*

Keep going even if a form slips. Reuse a chunk from weeks one or two if you get stuck.

## Day 22 — A trip, regular past

**Vocabulary:** viajar, visitar, llegar, salir  
**Grammar:** full regular preterite  
**Listen:** someone recounting a trip  
**Practice:** tell a short trip story using four different verbs and persons

### Grammar

**The full chart, from the day 13 chunks.** Day 13 only gave you the yo form of a handful of verbs as fixed chunks: comí, trabajé, cené. Now every person of a regular verb follows one of two patterns: -ar verbs use -é, -aste, -ó, -amos, -aron; -er and -ir verbs share -í, -iste, -ió, -imos, -ieron.

| | viajar (-ar) | salir (-ir) |
|---|---|---|
| yo | viajé | salí |
| tú | viajaste | saliste |
| él / ella | viajó | salió |
| nosotros | viajamos | salimos |
| ellos / ellas | viajaron | salieron |

Visitar and llegar follow viajar exactly. Comer, from day 13, follows the same -er/-ir pattern as salir: comí, comiste, comió, comimos, comieron.

Not yet: verbs that change spelling in the yo form (llegué, not llegé) or the irregular verbs from day 23.

### Phrases

| Spanish | English | Note |
|---|---|---|
| Viajé a España el año pasado. | I travelled to Spain last year. | |
| ¿Visitaste el museo? | Did you visit the museum? | |
| Llegamos tarde al aeropuerto. | We arrived late at the airport. | |
| Mis padres viajaron a Perú. | My parents travelled to Peru. | |
| Salieron del hotel a las ocho. | They left the hotel at eight. | |
| ¿A qué hora llegaste? | What time did you arrive? | |
| Comimos en un restaurante local. | We ate at a local restaurant. | |
| Visitamos tres ciudades en una semana. | We visited three cities in one week. | |
| Salí de casa muy temprano. | I left home very early. | |
| Ella llegó antes que nosotros. | She arrived before us. | |

### Dialogue — Telling a friend about the trip

- **Marta:** ¿Cómo fue tu viaje? — How was your trip?
- **Alex:** Viajé a Portugal con mi familia. Visitamos Lisboa y Oporto. — I travelled to Portugal with my family. We visited Lisbon and Porto.
- **Marta:** ¿Llegasteis... perdón, llegaron bien? — Did you all arrive OK?
- **Alex:** Sí. Llegamos tarde el primer día, pero después todo fue bien. — Yes. We arrived late the first day, but after that everything was fine.
- **Marta:** ¿Comisteis bien? — Did you eat well?
- **Alex:** Comimos mucho pescado. Salimos a caminar todas las tardes. — We ate a lot of fish. We went out walking every afternoon.

### Practice — A short trip story

Tell the story of a real or imagined trip in four or five sentences. Use viajé/viajamos, visité/visitamos, llegué/llegamos, and salí/salimos — mix yo and nosotros, and add one él/ella or ellos sentence about someone else on the trip.

**Grammar:** full irregular preterite  
**Listen:** friends comparing what they each did

## Day 24 — Childhood

**Vocabulary:** games, school, habits  
**Grammar:** the imperfect  
**Listen:** someone describing what they were like as a child  
**Practice:** describe three things you used to do as a child

### Grammar

**For what used to happen, not what happened once.** The preterite (days 13, 22, 23) tells a finished event. The imperfect describes a habit, a background state, or something repeated — with no clear end in view. -ar verbs use -aba, -abas, -aba, -ábamos, -aban. -er and -ir verbs share -ía, -ías, -ía, -íamos, -ían.

| | jugar (-ar) | vivir (-ir) |
|---|---|---|
| yo | jugaba | vivía |
| tú | jugabas | vivías |
| él / ella | jugaba | vivía |
| nosotros | jugábamos | vivíamos |
| ellos / ellas | jugaban | vivían |

Ser is irregular: era, eras, era, éramos, eran. *Cuando era niño/a* is the phrase that usually starts these stories.

Not yet: ir and ver in the imperfect (iba, veía). Keep the story to jugar, vivir, ser, and verbs you already know from days 9 and 10.

### Phrases

| Spanish | English | Note |
|---|---|---|
| Cuando era niño, jugaba en el parque. | When I was a child, I used to play in the park. | |
| Vivíamos en un pueblo pequeño. | We used to live in a small town. | |
| Mis padres trabajaban mucho. | My parents used to work a lot. | |
| Ella era muy tímida de pequeña. | She was very shy as a child. | |
| Estudiábamos por la tarde. | We used to study in the afternoon. | |
| Mi hermano y yo jugábamos todos los días. | My brother and I used to play every day. | |
| Comía mucho helado. | I used to eat a lot of ice cream. | |
| Mi abuela cocinaba todos los domingos. | My grandmother used to cook every Sunday. | |
| No tenía teléfono. | I didn't have a phone (back then). | |
| Era muy feliz en esa época. | I was very happy in that time. | |

- **Lucía:** ¿Cómo eras de niña? — What were you like as a child?

## Day 25 — Telling a story

**Grammar:** preterite with imperfect

**Practice:** tell an anecdote combining both

### Grammar

**Background paints the scene; the event happens inside it.** Use the imperfect for what was going on — the weather, the time, how you felt, what you were doing — and the preterite for the single thing that then happened. ## Day 27 — Plans and predictions

**Grammar:** regular and irregular future

### Grammar

**One set of endings on the whole infinitive.** Day 4 already covered the near future with ir + a + infinitive (voy a viajar). This is the other future — add -é, -ás, -á, -emos, -án straight onto the infinitive. A short list of common verbs shorten the infinitive first, but keep the same endings.

| | viajar | hacer (irregular stem) | tener (irregular stem) |

Tener que + infinitive = have to. Hay que + infinitive = a rule for everyone, no person attached.

### Stem-changing verbs (day 16)

- e→ie: empezar → empiezo, empiezas, empieza, empezamos, empiezan
- o→ue: poder → puedo, puedes, puede, podemos, pueden; dormir the same way
- e→i: pedir → pido, pides, pide, pedimos, piden

Nosotros keeps the original vowel in all three patterns.

### Object, possessive, and demonstrative pronouns (days 17, 18, 19)

- Direct object: lo, la, los, las — replace the noun already mentioned. *Lo tengo. La veo.*
- Indirect object with gustar-type verbs: me, te, le, nos, les + gusta/gustan, duele/duelen, encanta(n), interesa(n).
- Possessives: mi(s), tu(s), su(s), nuestro/a(s) — nuestro matches gender and number; the rest only match number.
- Demonstratives: este/esta (near me), ese/esa (near you), aquel/aquella (far from both).

### Comparing (day 20)

- más...que / menos...que — unequal comparison.
- tan...como — equal comparison.
- el/la/los/las + más/menos — superlative.
- Irregular: bueno → mejor, malo → peor, grande → mayor, pequeño → menor.

### Imperfect (day 24)

| | -ar (jugar) | -er/-ir (vivir) |
|---|---|---|
| yo | jugaba | vivía |
| tú | jugabas | vivías |
| él / ella | jugaba | vivía |
| nosotros | jugábamos | vivíamos |
| ellos / ellas | jugaban | vivían |

Ser is irregular: era, eras, era, éramos, eran.

### Preterite with imperfect (day 25)

Imperfect sets the background; preterite gives the single event: *Estaba durmiendo cuando sonó el teléfono.*

### Commands (day 26)

| Type | Example |
|---|---|
| tú, affirmative | Corta. Come. Escribe. (irregular: di, ve, ten, pon, sal, sé, ven) |
| tú, negative | No cocines. No hables. |
| usted, affirmative | Hable. Coma. Escriba. |
| usted, negative | No se preocupe. |

### Future (day 27)

Regular: add -é, -ás, -á, -emos, -án to the infinitive. Common irregular stems: tener → tendr-, hacer → har-, poder → podr-, querer → querr-, decir → dir-, salir → saldr-, venir → vendr-.

### Health and advice (day 29)

- Deber + infinitive = should. *Debo descansar.*
- Poder + infinitive = can. *Puedo esperar.*
- Tener que + infinitive = must. *Tengo que ir al médico.*
- Doler follows the gustar pattern. *Me duele la cabeza. Me duelen los pies.*

### What these two weeks do not cover

Left for later, on purpose: the full subjunctive, the conditional tense, compound tenses (he hablado, había hablado), the passive voice, tanto/a/os/as como, the long possessive forms (mío, tuyo, suyo), vosotros throughout, and formal ustedes as a separate verb ending from the singular usted.
